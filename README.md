# TwoFish-C#-Implementation

📌 Overview

This project implements the Twofish symmetric encryption algorithm in C# to demonstrate secure data encryption and decryption using a shared secret key.

🔐 What is Twofish?

Twofish is a symmetric block cipher and a finalist in the AES competition. It encrypts data in fixed-size blocks using a single shared key and is designed to be fast, flexible, and secure.

⚙️ Features

Symmetric key encryption

Symmetric key decryption

Configurable key usage

Test cases validating correct encryption and decryption

Demonstration that incorrect keys produce invalid output
